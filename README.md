# 📚 LMS App

Sistem Learning Management System (LMS) berbasis web yang dikembangkan menggunakan Laravel.  
Project ini dibuat untuk mendukung proses pembelajaran online dengan fitur manajemen course, materi, dan evaluasi.

---

## 🚀 Fitur Utama

- 🔐 Authentication (Login & Register)
- 👨‍🏫 Manajemen Course (Guru/Admin)
- 📖 Material / Materi Pembelajaran
- 📝 Quiz & Assignment
- 📊 Submission & Tracking
- 🏆 (Planned) Gamifikasi: Point, Badge, Rank
- 📈 Report & Analytics

---

## 🛠️ Tech Stack

- Backend: Laravel
- Frontend: Blade / (Planned: React / SPA)
- Styling: Tailwind CSS
- Database: MySQL
